# Folia 桌面跟随悬浮（`folia-desktop-follow`）

在 Folia 托盘右键菜单中新增两个独立勾选项，不修改 Folia 源码：

- **「跟随桌面」**（位于「透明背景」下方，与「窗口置顶」双向互斥）：保留透明背景与自由尺寸，桌面露出（含 `Win + D`）时一起显示，被其他应用覆盖时一起被盖住；点击 Folia 临时浮起，点别处自动退回桌面层。
- **「半穿透」**（位于「点击穿透」下方，与原生「点击穿透」双向互斥）：鼠标位于 Folia 的按钮、进度条、标题栏拖拽区、弹窗或主页等可操作区域时正常响应点击与拖拽；位于透明空白区域时自动穿透到后方的桌面或其他软件。

## 使用方式

1. 在 Folia **设置 → 模组 → 模组市场 → 更多操作（…）→ 重新加载模组**，启用 **桌面跟随悬浮** 并确认。
2. 右键 Folia 系统托盘图标，按需勾选 **透明背景**、**跟随桌面**、**半穿透** 即可。
3. 开启 **跟随桌面** 时默认启用桌面小组件窗口样式与事件驱动桌面层锚定，`Win + D` 显示桌面无最小化闪烁（关闭跟随桌面后自动恢复原窗口样式）。
