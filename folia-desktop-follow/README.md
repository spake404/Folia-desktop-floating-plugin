# Folia 桌面跟随悬浮（`folia-desktop-follow`）

通过 Folium 模组设置页与全局快捷键提供两项独立能力（纯源码实现，无预编译二进制，不修改 Folia 源码）：

- **「跟随桌面」**（与「窗口置顶」互斥）：保留透明背景与自由尺寸，桌面露出（含 `Win + D`）时同步显示且无最小化闪烁，被其他应用覆盖时一起被盖住；点击 Folia 临时浮起，点别处自动退回桌面层。
- **「半穿透」**：鼠标位于 Folia 的按钮、进度条、标题栏拖拽区、弹窗等可操作区域时正常响应点击与拖拽；位于透明空白区域或当前位置被其他前景软件遮挡时自动保持穿透。

## 使用方式

1. 在 Folia **设置 → 模组** 中启用 **桌面跟随悬浮**。
2. 展开本模组的 **设置** 面板，按需开启 **跟随桌面**、**半穿透**（推荐同时开启 Folia 托盘的 **透明背景**），也可在快捷键设置中为「切换桌面跟随悬浮」「切换半穿透」绑定全局快捷键。
3. 关闭「跟随桌面」或停用模组时自动恢复原窗口样式。
